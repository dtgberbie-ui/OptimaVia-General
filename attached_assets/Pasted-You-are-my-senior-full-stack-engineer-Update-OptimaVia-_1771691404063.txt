GOAL:
Allow employers to publish a single job posting inside OptimaVia and distribute it to external job boards where feasible. Because some job boards (e.g., LinkedIn, Indeed) require partner approval or have limited APIs, implement a tiered approach:

3) MANUAL POSTING ASSIST (universal fallback):
   - Provide “Copy job posting” + “Copy apply link” buttons.
   - Provide an “AI rewrite for job board” tool to tailor the description (if OpenAI key present; otherwise template).
   - Provide a checklist per board with outbound links and steps.

Create a new “Hiring” section in the employer dashboard with these pages:

A) Hiring Dashboard

   - Button: “Post a Job”

B) Job Posting Editor (OptimaVia-native)
   - Standard fields: title, industry, department (optional), employment type, location (country + region/state + city),
     pay range, description, responsibilities, requirements, required certifications, schedule, benefits.
   - Save as Draft / Publish.

C) Distribute Job (New page)
   - After publishing, show a “Distribution” panel with:
     - Toggle: Include in OptimaVia job board (ON by default)

        - Feed URL (copy button)

        - Preview of XML
     - Section: “Direct Integrations” with tiles:
        - Indeed (status: Requires Partner Access by default)
        - LinkedIn (status: Requires Partner Access by default)

        - Buttons: Copy job text, Copy apply link, Generate board-specific version
